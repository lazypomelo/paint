Features

  • Lightweight single-file drawing app
  • No installation required
  • Drawings are stored in browser local storage (IndexedDB)
    • IndexedDB stores data per browser and per file. As long as the .html file stays in the same location, and is accessed via the same browser, previously generated drawings remain available.
  • Shapes are in SVG format, user is invited to paste any SVG graphics - e.g. taken from svgrepo.com
  • Pasting screenshots from clipboard works too
